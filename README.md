## Как открыть

1. Дважды нажать на `Запустить сайт.cmd`.
2. Оставить открывшееся окно работающим.
3. Открыть в браузере http://localhost:8003/.

Чтобы остановить сервер, нажать Ctrl+C в его окне.
Если порт 8003 уже занят работающим экземпляром сайта, достаточно открыть указанный адрес.

PHP уже установлен вместе с XAMPP: `C:\xampp\php\php.exe`.
Запуск из PowerShell в папке ЛР3 без командного файла:

```powershell
& 'C:\xampp\php\php.exe' -S localhost:8003
```

Файлы `.php` нужно открывать через сервер по HTTP: двойной щелчок по самому PHP-файлу не выполняет программу.
Это локальный запуск на этом компьютере. Для доступа из интернета файлы сайта нужно разместить на хостинге с поддержкой PHP.

## Файлы и обязательные элементы

- `index.php` — информация из ЛР1, список интересов и две фотографии.
- `study.php` — учёба, список предметов и таблица из ЛР1.
- `web.php` — краткий текст о HTML, CSS и PHP со списком технологий.
- `style.css` — общее оформление на основе ЛР1.
- `images/` — две фотографии.

На каждой странице один h1, два h2, список и не менее 1 КБ основного текста в UTF-8. Макет и меню одинаковые.
Шапка имеет высоту 120 пикселей и остаётся на месте при прокрутке. Подвал имеет высоту 110 пикселей и расположен внизу страницы; при коротком содержимом его опускает вниз `flex: 1` у main.

Заголовок вкладки хранится в `$title`. Списки выводятся из массивов циклом `foreach`.
Каждая ссылка меню содержит ровно два фрагмента PHP: первый задаёт переменные и выводит адрес, второй выводит класс активной ссылки и её текст. Код одинаков, меняются только значения переменных.

На главной странице `if` проверяет остаток от деления текущей секунды на 2. В чётную секунду первой выводится `workspace.jpg`, в нечётную — `laptop.jpg`. Вторая фотография меняется в обратном порядке. Для проверки нужно обновлять страницу: автоматическое обновление не требуется заданием.
Дата и время формирования выводятся в подвале по московскому времени. Один и тот же момент `$time` используется для выбора фотографий и времени в подвале.
